# EntryStage

Extension Gravity Forms : affiche les entrées d'un formulaire sur le site, en liste responsive.

Page WordPress.org : https://wordpress.org/plugins/entrystage/

Ce dépôt sert au déploiement : une release GitHub dont le tag reprend le « Stable tag » du readme.txt (ex. `1.0.0`) envoie automatiquement la version sur le SVN de WordPress.org.
